# Interview Answers

These answers are assignment evidence created for the case analysis. They must not be generalized beyond their stated meaning.

| ID | Stakeholder | Interview answer |
|---|---|---|
| EL-01 | Lecturer | I need to create an assignment for one course, describe it, and set its deadline before publishing it. |
| EL-02 | Lecturer | I need to see each student's submission and record a numeric grade with written feedback. |
| EL-03 | Lecturer | I need a course-level summary showing which students have submitted and which remain outstanding. |
| EL-04 | Student | I need one list of my assigned tasks showing course, deadline, and current status. |
| EL-05 | Student | When I upload a submission before the deadline, I need confirmation that the system recorded it. |
| EL-06 | Student | I need to see whether my work is not submitted, submitted, graded, or returned with feedback. |
| EL-07 | Student | A visible in-application reminder for a deadline within 24 hours would help me avoid missing work. |
| EL-08 | Student | If a deadline has passed, the system should clearly explain why a normal submission is rejected. |
| EL-09 | Administrator | I need to create, update, deactivate, and assign users to courses according to their role. |
| EL-10 | Administrator | I need a report of task and submission activity by course for operational support. |
| EL-11 | Administrator | Only users assigned to a course should access that course's assignments and submissions. |
| EL-12 | Lecturer | Only the lecturer assigned to the course should publish assignments or change grades for that course. |
